# Ananya Goyal — Portfolio (with self-editable admin panel)

A Next.js version of the portfolio. Same look (black-hole vortex
background, custom cursor, cosmic theme), but now:

- All content (skills, certificates, projects, education, profile/hero
  text, resume link) lives in a MongoDB database instead of the HTML.
- A password-protected `/admin` panel lets you add, edit, and delete
  everything yourself — no code changes, no redeploy needed. Edits
  appear on the live site the moment you save.
- Animations are rebuilt with Framer Motion (spring-based reveals,
  mouse-tilt on the portrait / project / certificate cards) for a
  livelier feel than the old plain-CSS version.
